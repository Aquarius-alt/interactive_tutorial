PRESS START 2P

This project uses the Windows font family "Press Start 2P" for all interface text.

Before launching the application:
1. Install Press Start 2P in Windows.
2. Close and reopen the application so Windows can load the new font.
3. In Visual Studio, run Build > Rebuild Solution.

Official font page:
https://fonts.google.com/specimen/Press+Start+2P

The font includes Cyrillic characters, so Russian repository names, notes, tests,
and answers can be displayed in the same typeface.
